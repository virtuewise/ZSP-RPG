# Original art — ZIMBABWE: THE SHADOW PROTOCOL

All files in this folder tree are original to this project.
Nothing here comes from the Commando APK, its SDK, its ad network, or Unity's splash screen.

- `UI/zsp_emblem.png` — conical tower, sun, msasa hills. Transparent background.
- `UI/zsp_logo.png` — wordmark for menu/loading screens.
- `UI/zsp_splash.png` — 2048×1152 title/loading image.
- `UI/zsp_crosshair.png` — reticle.
- `UI/zsp_health_bar.png`, `UI/zsp_detection_bar.png` — HUD bars.
- `Icons/zsp_app_icon_512.png` — app icon master.
- `Textures/zsp_nightjar_weave.png` — placeholder fabric weave for Nightjar fatigues.

Regenerate with `python tools/make_brand_assets.py` from the workspace root.

Do **not** add extracted APK art to this folder. Add only original or licensed work,
and record the licence next to the file.
